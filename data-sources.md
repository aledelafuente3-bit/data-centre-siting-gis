# Data-source publication checklist

The public repository should document source, date accessed, spatial resolution, licence or terms, processing step and final criterion for every input dataset. Raw files should remain outside GitHub unless their terms and size clearly permit redistribution.

| Theme | Principal source | Repository treatment |
|---|---|---|
| Projected water stress | World Resources Institute | Cite and provide acquisition instructions |
| Projected extreme heat | NASA NEX-GDDP-CMIP6 | Cite and provide processing instructions; exclude NetCDF files |
| Multi-hazard exposure | FEMA | Cite and provide acquisition instructions |
| Transmission infrastructure | HIFLD and supporting public sources | Cite and document processing |
| Internet infrastructure | CAIDA and derived IXP layers | Review terms; publish metadata and derived methodology only where permitted |
| Major roads | U.S. Census TIGER/Line and/or OpenStreetMap | Cite relevant source and licence |
| Grid carbon intensity | EPA eGRID | Cite edition and balancing-authority assignment method |
| Thermoelectric freshwater consumption | USGS and electricity-system data | Cite sources and document balancing-authority aggregation |
| Community burden | CDC/ATSDR environmental-justice data | Cite edition and processing method |
| Protected areas and land cover | USGS PAD-US and NLCD | Cite editions; exclude bulk rasters and geodatabases |
